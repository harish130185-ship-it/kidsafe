Privacy Policy — KidSafe Activity Monitor

Effective Date: November 28, 2026  |  Package ID: com.kidsafe.monitor  |  Contact: harish130185@gmail.com

Transparent Family Monitoring Commitment: KidSafe Activity Monitor is a guardian-authorized parental supervision tool. It is designed strictly for parents and legal guardians monitoring their own family's devices with explicit disclosure on the child device.

1. Data We Collect

  • Parent Account Info: Parent email address, display name, and hashed authentication credentials used to sign in to the Parent Dashboard.
  • Child Profile & Device Info: Child nickname/profile name, age setting, daily screen-time limit, device model, Android OS version, and battery percentage.
  • App Usage & Activity Data: Foreground application package names, app categories, approximate daily usage duration, and screen unlock timestamps obtained via Android UsageStatsManager (requires explicit PACKAGE_USAGE_STATS grant by the parent).

2. Data We Strictly DO NOT Collect

  • No private messages, SMS, WhatsApp/social chats, or emails.
  • No keystrokes, passwords, banking details, or screen captures/screenshots.
  • No camera feeds, microphone audio, call logs, contacts, or photos.
  • No background GPS/precise location tracking.

3. Prominent Disclosure of Sensitive Android Permissions

  • Usage Access (PACKAGE_USAGE_STATS): Used exclusively to calculate daily screen time per app and display activity timelines to the paired parent.
  • Accessibility Service (Optional, BIND_ACCESSIBILITY_SERVICE): Disabled by default and configured with canRetrieveWindowContent="false". When explicitly enabled by the parent, it detects only the foreground app package name (TYPE_WINDOW_STATE_CHANGED) to enforce parent-configured app blocks or bedtime limits. It never reads screen text, notifications, or user input.
  • Persistent Transparency Notification (Foreground Service): While monitoring is active, KidSafe displays an ongoing visible notification on the child device informing the user that monitoring is enabled.

4. Data Storage, Security & Sharing

All telemetry between the Android app and the KidSafe server is encrypted in transit over HTTPS (TLS). Data is stored in our cloud PostgreSQL database (Neon) isolated by authenticated parent account. We do not sell, rent, or share any parent or child data with advertisers or third-party data brokers.

5. Data Retention & Deletion

Parents can choose a retention period (7, 14, 30, or 90 days) inside Settings, remove individual child profiles at any time, or permanently delete their entire account and all associated telemetry either inside the app (Settings → Danger Zone) or online at https://kidsafe.railplus.in/delete-account.

6. Children's Privacy

Only parents or legal guardians may create accounts and authorize device pairing using a single-use pairing code and guardian password authentication. If you believe data was collected without proper guardian consent, contact harish130185@gmail.com for immediate removal.
